# ZeroVector Directives
- Subsystem `ZeroVector.Core`: In-memory and embedded Vector Database, SIMD-accelerated distance metrics (DotProduct, Cosine, Euclidean, Manhattan, Hamming), Flat contiguous vector index, and Hierarchical Navigable Small World (HNSW) graph index.
- Multi-targeting: `netstandard2.0;net462;net8.0` (compatible with .NET Framework 4.6.2 - 4.8 and modern .NET).
- Zero external dependencies: Pure C# implementation with zero external third-party libraries.
- Strict Zero-LOH and Zero-Allocation memory discipline on similarity search hot paths.
