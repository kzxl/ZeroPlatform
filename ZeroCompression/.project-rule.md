# ZeroCompression Directives
- **Zero-Allocation Hot-Paths:** Never allocate unmanaged buffers or large byte arrays on hot paths; use `ArrayPool<byte>.Shared` or `Span<byte>`.
- **Sovereign Codec Standard:** Adhere to Pure C# / Sovereign BCL where possible. Avoid monolithic 3rd-party compression suites.
- **Contract-First Extensibility:** All compression codecs must implement `ICompressionCodec` and register with `CodecRegistry`.
- **Authenticated Integrity:** Always ensure integrity verification (CRC32 and AES-256-GCM AEAD) runs with single-pass zero-redundant I/O.
