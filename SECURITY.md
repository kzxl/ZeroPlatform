# Security Policy

ZeroPlatform is designed for mission-critical industrial automation, defense, and edge computing environments. We treat security vulnerabilities with the highest priority.

---

## 🛡️ Supported Versions

| Version | Supported          | Status                      |
| ------- | ------------------ | --------------------------- |
| 1.x     | :white_check_mark: | Active (Current Major Track)|

---

## 🚨 Reporting a Vulnerability

If you discover a potential security flaw in ZeroPlatform or any of its 12 satellite repositories, please report it privately:

### 1. Contact
- **Email**: [kazer.vj@gmail.com](mailto:kazer.vj@gmail.com)
- **Subject**: `[SECURITY] ZeroPlatform Vulnerability: <Subsystem / Summary>`
- Alternatively, use [GitHub Security Advisories](https://github.com/kzxl/ZeroPlatform/security/advisories/new).

### 2. Required Details
Please include:
- The affected subsystem (e.g., `ZeroComm`, `ZeroNetwork`, `ZeroStorage`).
- Step-by-step reproduction instructions or PoC.
- Assessed impact and potential mitigations.

### 3. Response SLA
- Initial acknowledgement within **48 hours**.
- Coordinated remediation and synchronized patch release across the satellite network.
