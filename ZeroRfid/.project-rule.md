# Project Configuration & Development Standards (ZeroRfid)

Tên dự án hiện tại: **ZeroRfid**
Hệ sinh thái: **ZeroPlatform**

---

## 1. Giới thiệu & Mục tiêu
`ZeroRfid` là bộ thư viện xử lý RFID tốc độ cao cho .NET với tôn chỉ **Zero External Dependencies** ở tầng Core, đa mục tiêu (`netstandard2.0;net462;net8.0`).

Các phân hệ chính:
- **`ZeroRfid.Core`**: Định nghĩa sovereign abstractions (`IRfidReader`, `IRfidMemoryAccess`, `IRfidGpioController`), model `TagReadEvent` chuẩn hóa, codecs mã hóa/giải mã EPC Hex và GS1 TDS (SGTIN-96, SSCC).
- **`ZeroRfid.Adapters.Abstractions`**: Khung nền tảng Adapter giúp bọc các SDK phần cứng của bên thứ ba (Zebra, Impinj, Hopeland) mà không làm ảnh hưởng tầng Core.
- **`ZeroRfid.Pipeline`**: Bộ lọc dữ liệu luồng tốc độ cao (Sliding-window Deduplication, RSSI Threshold, Portal Gate Inbound/Outbound Direction Resolver).
- **`ZeroRfid.Simulator`**: Đầu đọc giả lập đa kịch bản (cổng kho, băng chuyền, kiểm kê tĩnh) phục vụ dev & unit test tự động.

---

## 2. Quy chuẩn Phát triển & Kiến trúc
- **Ports & Adapters (Hexagonal)**: Core không tham chiếu SDK vendor nào. Các adapter kết nối hãng phải kế thừa `VendorReaderAdapterBase`.
- **Zero-Allocation**: Tối ưu chuyển đổi Hex/Bytes bằng Span và bộ nhớ tĩnh.
- **Thread Safety**: Các luồng đọc thẻ dùng `System.Threading.Channels` kết hợp event UI an toàn.
- **Trusted Publishing**: Tích hợp GitHub Actions workflow OIDC token exchange phát hành trực tiếp lên NuGet.org và GitHub Packages.

---

## 3. Lệnh Hữu ích
*   **Build Solution:**
    ```bash
    dotnet build ZeroRfid.slnx -c Release
    ```
*   **Chạy Unit Tests:**
    ```bash
    dotnet test tests/ZeroRfid.Tests/ZeroRfid.Tests.csproj -c Release
    ```
*   **Đóng gói NuGet nội bộ:**
    ```powershell
    pwsh -File ./pack.ps1 -Configuration Release
    ```
