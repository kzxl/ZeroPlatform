# ZeroPrimitives Directives (Tier 0A Bedrock)

Read `../.project-rule.md` §2 before any version bump, NuGet pack, or release tag.
Read `../.project-rule.md` §4 before every commit (timestamped commit format, scope `primitives`).
Read `../.project-rule.md` §5 before any version bump or tag: bump/tag only on an explicit user NuGet release request; otherwise log changes under `## Unreleased` in `CHANGELOG.md`.

## 1. Independent Versioning & Release
- **Version SSOT**: Edit `<VersionPrefix>` in `ZeroPrimitives/Directory.Build.props` (monotonic forward from `3.1.0`; never downgrade).
- **Binary Stability (`net462`)**: Keep `<AssemblyVersion>` frozen at `3.1.0.0` across all `3.x.y` releases; set `MAJOR.0.0.0` only on major releases (`4.0.0.0`+).
- **Release Trigger**: Push tag `primitives-v<VersionPrefix>` (or `primitives-v<VersionPrefix>-<suffix>`) to invoke `.github/workflows/publish-packages.yml (`publish-primitives` job)`.
- **CLI Override**: Use `-p:PrimitivesVersion=X.Y.Z` for ad-hoc packs; never pass `-p:Version=...` across the monorepo solution.

## 2. Tier-0A Boundary & Multi-TFM Invariants
- **Zero Platform Dependencies**: `ZeroPrimitives.Core` must maintain `0` internal `Zero*` references and `0` external NuGet dependencies on `net8.0` (only Microsoft BCL backport packages on `netstandard2.0`/`net462`).
- **Scope Guard**: Keep pure low-level primitives (`Buffers`, `Memory`, `Identifiers`, `Diagnostics`, `Parsing`, `Text`, `Simd`, `FastCrc`/`FastHash`, `FastConvert`). Place lock-free scheduling/channels/IPC in `ZeroConcurrency`, full cryptography in `ZeroSecurity`, linguistic/regex algorithms in `ZeroText`, and regional/ERP business rules outside Tier 0A.
- **Multi-TFM Test Gate**: Verify every change with `dotnet test ZeroPrimitives/tests/ZeroPrimitives.Tests/ZeroPrimitives.Tests.csproj -c Release` (must pass 100% on both `net8.0` and `net462`, exit `0`).
