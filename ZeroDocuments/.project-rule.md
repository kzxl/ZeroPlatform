# Project Specific Directives: ZeroDocuments
- **Core Principle:** 100% Pure C# BCL, Zero External Dependencies (No EPPlus, ClosedXML, NPOI, or DocumentFormat.OpenXml).
- **Streaming-First Architecture:** Always use forward-only XML reading (`XmlReader`) and ZIP streaming (`ZipArchive`) to maintain memory usage under 15MB regardless of worksheet size.
- **Reflection Elimination:** Always utilize compiled Expression Trees via `PropertyAccessorCache` for POCO/DTO serialization and hydration.
- **Security Guard:** Always enforce CWE-1236 mitigation (Formula/CSV Injection protection) by prefixing unsafe characters (`=`, `+`, `-`, `@`, `\t`, `\r`) with single quotes.
- **Git Commit Discipline:** Strictly adhere to `R_GIT`. Every commit must be atomic. Production code and unit tests must be committed together.
- **Issue Resolution & Release Protocol:**
  - When resolving issues or PRs, acknowledge and thank the reporter.
  - Transparently state the root-cause and fix in issue responses and git commit messages (`(fixes #<id>)`).
  - Bump SemVer version in `Directory.Build.props` and release package immediately for bugfixes or features.
