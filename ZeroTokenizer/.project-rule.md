# ZeroTokenizer Directives
- Subsystem `ZeroTokenizer.Core`: High-speed zero-allocation Byte-Pair Encoding (BPE), Tiktoken regex-aware tokenization, LLM context token budgeter (Knapsack packing), and streaming decoders in 100% pure C#.
- Multi-targeting: `netstandard2.0;net462;net8.0`.
- Zero external dependencies: Pure C# implementation with zero external third-party libraries.
- Strict Zero-LOH and Span-based memory discipline on tokenization hot paths.
