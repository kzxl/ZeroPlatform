# ZeroAudio Directives
- Adhere strictly to sovereign zero-dependency architecture: 100% pure C# BCL, 0 unmanaged external libraries (no NAudio, FFmpeg, or BASS DLLs).
- Minimal allocation, maximum efficiency: reuse buffers via ArrayPool, slice Spans, avoid boxing in real-time audio hot paths.
- Multi-targeting compatibility across .NET 8.0+, .NET Framework 4.6.2+, and .NET Standard 2.0.
