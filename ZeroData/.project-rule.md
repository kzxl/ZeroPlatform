# ZeroData Directives
- Subsystem `ZeroData.Core`: In-memory Columnar DataFrame, SIMD Vectorization, Apache Arrow IPC streaming.
- Subsystem `ZeroData.Sql`: High-speed hybrid RDBMS data access, Dapper-backed execution, modern ergonomic syntax, fast primary-key lookups, batch operations, LINQ-to-SQL parity.
- Subsystem `ZeroData.Sql.CodeGen`: CLI tool (`zerodata-sql-codegen`) for reverse-engineering DBML models and SQL databases.
- Multi-targeting: `netstandard2.0` (compatible with .NET Framework 4.6.2 - 4.8 and .NET Core / .NET 8/9/10).
- Zero unnecessary allocations in hot paths per `[AgentOption]/standards/csharp/high-performance-compute.md`.
